# Contributing to Soundcorder

Thanks for your interest in Soundcorder. It's an early-stage, audio-first sound journal, and help is genuinely welcome — whether that's code, bug reports, or ideas.

## Ways to help

- **Report bugs.** Open an issue with what you did, what you expected, and what happened. Device and OS version help a lot.
- **Suggest features.** Open an issue describing the idea and the problem it solves. Keep the "simple, no limits" spirit in mind.
- **Submit code.** Fork the repo, make your change on a branch, and open a pull request.

## Pull requests

1. Fork and branch from `main` (e.g. `feature/export-wav` or `fix/record-crash`).
2. Keep changes focused — one thing per PR is easier to review.
3. Describe *what* changed and *why* in the PR.
4. Make sure the app still builds and runs before submitting.

## Ground rules

Be decent to each other. Assume good faith, keep discussion on the work, and help keep this a welcoming place to build something.
